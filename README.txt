FIT กับฉัน — PWA สำหรับ Android (พร้อมนำขึ้นออนไลน์)

ไฟล์ในโฟลเดอร์นี้ต้องอยู่ด้วยกันทั้งหมด:
- index.html — แอปหลัก: บันทึกน้ำหนัก/รอบเอว/น้ำดื่ม/กิจวัตร/การฝึก
- เมนูอาหาร_ลดน้ำหนัก_30วัน.html — เมนู 30 วันพร้อมวิธีทำ
- manifest.json — ข้อมูลติดตั้งเป็นแอป
- sw.js — เก็บไฟล์สำหรับใช้งานออฟไลน์หลังโหลดครั้งแรก
- icon-192.png และ icon-512.png — ไอคอนแอป

วิธีนำขึ้นออนไลน์ฟรีด้วย GitHub Pages (ใช้มือถือได้ แต่คอมพิวเตอร์ทำง่ายกว่า):
1. สร้าง/เข้าสู่ระบบบัญชีที่ https://github.com
2. เปิด https://github.com/new แล้วตั้งชื่อ repository เช่น fit-kab-chan
3. เลือก Public (จำเป็นสำหรับ GitHub Free Pages ในการตั้งค่าทั่วไป) แล้วกด Create repository
4. เข้า repository > Add file > Upload files
5. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้โดยตรง ให้ index.html อยู่ระดับบนสุด ไม่ใช่ในโฟลเดอร์ย่อย แล้วกด Commit changes
6. เข้า Settings > Pages
7. ใน Build and deployment เลือก Deploy from a branch
8. เลือก Branch: main และ Folder: /(root) แล้วกด Save
9. รอให้ GitHub Pages เผยแพร่ แล้วเปิด URL ที่หน้า Settings > Pages แสดงให้ (รูปแบบ https://ชื่อบัญชี.github.io/ชื่อ-repository/)
10. เปิด URL ด้วย Chrome บน Android และรอให้แอปโหลดครบหนึ่งครั้งขณะออนไลน์
11. แตะเมนู ⋮ ของ Chrome > Install app หรือ Add to Home screen > Install/Add
12. เปิดแอปจากไอคอนหน้าจอหลัก ทดสอบเปิดเมนูอาหาร แล้วลองปิดอินเทอร์เน็ตเพื่อทดสอบออฟไลน์

ข้อควรทราบ:
- ต้องเปิด URL แบบ HTTPS จึงจะติดตั้ง PWA และใช้ Service Worker ได้; เปิดไฟล์ index.html จาก ZIP อย่างเดียวจะไม่เปิดโหมดออฟไลน์ PWA อย่างสมบูรณ์
- ข้อมูลบันทึกไว้ในเบราว์เซอร์ของมือถือเครื่องนั้น (localStorage) ไม่ซิงก์ข้ามเครื่องและอาจหายหากล้างข้อมูล Chrome/ถอนการติดตั้ง ควรกด “สำรองข้อมูล / ส่งออก” เก็บไฟล์ JSON ไว้
- ต้องเปิดแอปและหน้าเมนูอาหารอย่างน้อยหนึ่งครั้งขณะออนไลน์เพื่อให้ไฟล์ถูกแคช
- หากแก้ไฟล์ในอนาคต ให้เปลี่ยน CACHE_NAME ใน sw.js (เช่น v3) ก่อนอัปโหลดใหม่เพื่อบังคับอัปเดตแคช
- เว็บไซต์ GitHub Pages เป็นสาธารณะ; ห้ามใส่ข้อมูลส่วนตัวหรือข้อมูลสุขภาพที่ไม่ต้องการเผยแพร่ลงในไฟล์เว็บ
- ฉันจัดเตรียมแพ็กเกจให้แล้ว แต่ยังไม่ได้เผยแพร่ในบัญชี GitHub ของคุณ เพราะต้องให้คุณเข้าสู่ระบบและกดเผยแพร่เอง
